The lights don't lie

Green: the mic is open. Blue: it's speaking. Red: the camera sensor is on, lit before it starts and put out after it stops. They're held above everything else on the rails, so no mood color, light show or call can cover them, and the dimmer and night caps can dim them but never put them out.

Set up the robot

Everything that makes this robot yours: its Wi-Fi, the voice server it checks in with, the token its control API asks for, and a tailnet if you use one. Leave a box empty to leave that alone. The voice server fills in the blanks it knows: itself as the voice server, and the token it already holds.

A robot that's on the network takes these straight away and reboots. One that isn't yet (a new one, or one whose Wi-Fi changed) gets them from a soma.yaml on its microSD card, which it reads once at boot and deletes. Neither way is a password kept here or by the voice server.

Firmware

The voice server fetches a release (checked against its SHA256SUMS) or takes a build of your own (stack-chan.bin), and offers it to the robot once, on its next check-in. The robot shows its progress and reboots into it; if the new one can't check in, it goes back to the old one on the next reboot.
